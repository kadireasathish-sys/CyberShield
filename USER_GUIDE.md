# User guide

- USER: register or log in, use New Incident to submit a report, then inspect incident details and add information where the API permits.
- ANALYST: log in, review assigned incidents, add comments, upload/download evidence, and update an investigation.
- ADMIN: review users, enable/disable accounts, review incident activity, and export reports.

Navigation visibility is not an authorization boundary. Backend access control is incomplete; this guide describes the intended use, not a guarantee of complete role isolation. Evidence accepts non-empty `.txt`, `.log`, `.csv`, `.json`, `.png`, `.jpg`, `.jpeg`, and `.pdf` files up to 20 MB. Demo login data is documented in SETUP.md and must only be used locally.
